# 08 · M6 审计协议：复现「测量口径」而非论文分数（2026-11-22）

M6 是几个里程碑里最特殊的一个。M4/M5 复现的是**模型侧机制**（环带采样、
控制码表示），M6 复现的是一把**尺子**：论文用「top-K 近邻同社区率相对随机基线
的 lift」论证社区粒度对嵌入评测的影响。本机不下 OpenAlex 全表、不建 10 万 CS
子图，只把这把尺子的构造、基线剥离、显著性判定端到端真跑一遍，并用
阴性/阳性对照证明它校准正确。

三段链路：`17` 受控建图 → `17b` 引文增强三层消融 → `18` 测量协议。
全部为机制/协议复现，**不是论文 Table 1 的效果复现**，绝对数字不外推。

## 1. 为什么必须有 17b：真实引文图立不起来

论文社区来自 OpenAlex 全表约 2.5B 条引文边。本机真实材料实测
（`_m6_graph_probe.py`）：

```
paper_metadata_mag_mesh.json  mean|R|=4.4  mean|C|=13.2 (均为截断片段)
BC 倒排 19548 keys -> min_shared=3 后仅 1 条边
CC 倒排 58207 keys -> min_shared=3 后仅 8 条边
direct = 50; 合图 44 边, mean_deg=0.02, 4421/4500 孤儿, 4458 个连通分量
所有 gamma 下 Leiden 都切出 4458 个单例社区, 层次 split=0
```

`papers.json` 只有 title/abstract（无 references）；qrels 与 4500 嵌入池只重叠
17 个 id。**BC/CC 算子写对了，但数据稀疏到三层叠加也救不回来**。因此降级为
「受控合成引文」：真值社区 → 合成 references/cited_by → 倒排 + Salton 加权
→ 两级 CPM，把「算子与因果机制」和「数据」拆开验证。

## 2. 17b 引文增强：direct + BC + CC 三层消融（实跑）

边定义从「A 引用 B」扩展成「A 与 B 共享引用结构」：

| 层 | 信号 | 建边条件 | 权重 |
|---|---|---|---|
| direct | 池内互引 | j 属于 refs[i] ∪ cits[i] | +1.0 |
| BC | 共同参考文献 | 共享外部 refs >= 3 | sh / sqrt(\|R_i\|·\|R_j\|) |
| CC | 共同被引 | 共享外部 cits >= 3 | 同上（换 cits） |

只用池外 id 做倒排（池内 id 归 direct，混进来会污染消融）；`cap=500` 防爆，
`min_shared=3` 去噪；三层往同一个 `edge_w` dict 上 `+=`，快照三次做消融。

| 层 | 边数 | 平均度 | 孤儿 | 分量 | L1 (comm/ARI) | L2 (comm/ARI) |
|---|---|---|---|---|---|---|
| direct | 1053 | 0.47 | 2716 | 3450 | 3450 / 0.009 | 3450 / 0.072, split=0 |
| +BC | 50559 | 22.47 | 0 | 30 | 30 / 1.000 | 240 / 1.000 |
| +BC+CC | 60685 | 26.97 | 0 | 30 | 30 / 1.000 | 240 / 1.000 |

第一行精确复现了真实数据的失败态。**诚实修正**：ARI 不是逐层上升而是
「跃升后饱和」——BC 单独就足够可分，CC 的边际贡献在边数/密度（+10126 边）
而非 ARI。合成 token 按 `l1_true/l2_true` 生成，故 `ARI=1` 是**设计出来的
可分性**，只证明「增强算子链让稀疏图变可分区」，不代表分区算法能力或论文效果。

## 3. 18 测量协议：口径修正与阴阳性对照

### 3.1 一行必须抠准的基线

`topk_same_rate` 用 `sim[j, qi] = -2.0` 排除自身、取 10 个**不同**近邻，
抽样框是「随机两篇不同论文」。旧式 `base = sum((n_c/n)^2)` 允许抽到自己，
系统性高估 `(1-base)/(n-1)`。18 统一改为排除自身版：

```
base_excl = (sum(n_c^2) - n) / (n(n-1))      # 权威口径
base_incl = sum((n_c/n)^2)                    # 旧口径, 仅记录
mc_base   = 蒙特卡洛, keep = (a != b)          # 与解析式同抽样框
lift      = rate / base_excl
```

`mc_base` 同步排除自配对；置换检验随机打乱标签（社区大小不变），每组标签
**各自**跑 1000 次得到自己的 lift 分布与 95% 区间——不能共用 L1 的区间，
细粒度组方差更大。以 `base_excl` 为分母时零信号置换分布均值应为 1，
这本身就是口径自检。

### 3.2 实跑结果（seed=42, K=10, MC=200000, perm=1000）

| 标签组 | 角色 | rate | base_excl | lift | 置换 95% CI | 判定 |
|---|---|---|---|---|---|---|
| L1 | 阴性主对照 | 0.03136 | 0.03312 | 0.9467 | [0.9387, 1.0635] | 区间内 |
| L2 | 阴性主对照 | 0.01082 | 0.01132 | 0.9563 | [0.9014, 1.1095] | 区间内 |
| L1_true | 仪器自检 | 0.03144 | 0.03312 | 0.9495 | [0.9380, 1.0595] | 区间内 |
| L2_true | 仪器自检 | 0.00364 | 0.00395 | 0.9232 | [0.8274, 1.1709] | 区间内 |
| L1_aug | 稳健性记录 | 0.03144 | 0.03312 | 0.9495 | [0.9420, 1.0589] | 不进判据 |
| L2_aug | 稳健性记录 | 0.00364 | 0.00395 | 0.9232 | [0.8444, 1.1879] | 不进判据 |
| MAG (2500/19类) | 阳性对照 | 0.5240 | 0.05250 | **9.98** | [0.934, 1.071] | 显著 >1 |

`VERDICT: PASS`（4 条阴性判据 + 1 条阳性判据全 OK）。

三条读法：

1. **lift≈0.92~0.96 是阴性对照的正确输出，不是 bug**。嵌入是冻结 SciBERT
   按论文文本编码，planted/增强图标签按随机连边生成，两者无因果关联，
   理论 lift 就该是 1。置换检验均值≈1、观测值落在区间内，证明协议
   **不会凭空造信号**。
2. **MAG lift=9.98 是阳性对照**，证明学科标签与文本语义相关、协议
   **能检出真信号**。两个对照一起成立，这把尺子才算校准。
3. `L1_aug/L2_aug` 数字与 `L1_true/L2_true` 完全相同（社区划分 ARI=1.0，
   只差标签编号），加它不为产生新数字，而是把 17b 增强图产物接进链条，
   证明「图结构上的最优分区在文本嵌入空间里仍无信号」。

细粒度组 `MC vs 解析` 相对偏差最大 4.14%（`base_excl≈0.00395`），是
20 万次抽样在极小基线上的相对波动，绝对差约 `1.6e-4`；解析式是权威口径，
MC 仅作校验，不影响判据。

### 3.3 G 闸：共用模块的规范化写法

按拍板，测量协议抽到 `src/data/audit.py` 供 18 与回归共用，G 闸不依赖任何
被 gitignore 排除的产物，用内联确定性小算例（200 篇 / 4 个均匀社区 /
标签与嵌入独立）自检：

```
[G ] exact=True analytic~mc=True perm_mean~1=True CI_covers_1=True
[G ] base_excl=0.2462 base_incl=0.2500 mc=0.2440 perm_mean=1.0034 CI=[0.869,1.143]
```

八闸回归 `VERDICT: PASS`，A~F 归档数字逐位不变。

## 4. 诚实边界（必须随结论一起读）

- 社区是受控 4500 节点合成图，**不是**论文 10 万 CS 子图 / 3.58M 引文社区；
  合成引文**不是** OpenAlex 全表 2.5B 边。任何绝对数字不与论文比较、不外推。
- 复现的是「Leiden 两级 CPM 算法链 + 引文增强算子链 + 测量协议/基线剥离/
  粒度对照规则」，**不是**论文检索增益或社区质量。
- `ARI=1` 是合成 token 按真值生成的可分性；`lift≈1` 是标签与文本独立下的
  阴性结果。两者都是「协议正确」的证据，不是「方法有效」的证据。
- γ2 采用「对齐论文规模」口径（L2=157，ARI 0.394）而非 ARI 最优口径
  （3e-2 → 387 社区 / ARI 0.736），这是规模与结构真值的取舍，已在 M6 前瞻
  拍板记录，此处不藏。
